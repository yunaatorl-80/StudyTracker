StudyTracker — application installable (PWA)
============================================

Ce dossier contient l'application prête à être mise en ligne.

1) Créer un compte sur https://github.com (gratuit) si tu n'en as pas.
2) Créer un nouveau dépôt public, par exemple "studytracker".
3) Dans ce dépôt : "Add file" > "Upload files", puis glisser TOUT le contenu
   de ce dossier (index.html, app.js, style.css, sw.js, manifest.webmanifest
   et le dossier assets). Valider ("Commit changes").
4) Onglet "Settings" > "Pages" : Source = "Deploy from a branch",
   Branch = "main", dossier = "/ (root)". Enregistrer.
5) Attendre 1 à 2 minutes : l'adresse s'affiche, du type
   https://TON-NOM.github.io/studytracker/

Installation :
- Ordinateur (Chrome / Edge) : ouvrir l'adresse, puis l'icône "Installer"
  dans la barre d'adresse (ou le bouton "Installer" dans l'application).
- iPad / iPhone : ouvrir l'adresse DANS SAFARI, puis bouton Partager
  (carré avec une flèche) > "Sur l'écran d'accueil".

Important : https est obligatoire pour l'installation et le mode hors ligne.
GitHub Pages le fournit automatiquement.

Mise à jour : remplacer les fichiers dans le dépôt ; l'application se met à
jour toute seule à la prochaine ouverture.
